Ritex Digital Profile - Vercel Ready Folder

Folder structure:

ritex-digital-profile/
├── index.html
└── assets/
    └── ritexlogo.svg

Before uploading to Vercel:

1. Add your company profile PDF inside the assets folder.
2. Rename the PDF exactly as:
   Ritex_Overseas_Company_Profile.pdf
3. Open index.html and replace the WhatsApp placeholder:
   +91 XXXXXXXXXX
   https://wa.me/91XXXXXXXXXX

WhatsApp link format example:
https://wa.me/919876543210

Do not use +, spaces, or hyphens in the wa.me link.

Upload method:
1. Go to https://vercel.com/drop
2. Drag and drop the complete ritex-digital-profile folder
3. Deploy
